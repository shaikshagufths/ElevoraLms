✦ Elevora – Learning Management System

Elevora is a modern, responsive Learning Management System (LMS) designed to make online learning simple, interactive, and accessible. It provides a platform where learners can explore courses, watch video lessons, track their learning progress, and get assistance through an AI-powered tutor.

🚀 Features

Home Page: Modern landing page with an intuitive user interface.

Course Library: Browse, search, and filter available courses.

Course Details: View course descriptions, curriculum, lessons, and reviews.

My Learning: Access enrolled courses and track lesson progress.

Video Lessons: Learn through embedded YouTube videos.

AI Tutor: Interactive AI-based learning assistance with notes and quiz generation.

Wishlist: Save interesting courses for future learning.

Shopping Cart: Add courses to the cart and explore the demo checkout process.

Instructor Section: Provides an option to add new courses.

Dark & Light Mode: Switch between themes for a comfortable learning experience.

Responsive Design: Accessible across different screen sizes and devices.

🛠️ Technologies Used

HTML5 – Structure of the application.

CSS3 – Styling, responsive layouts, and themes.

JavaScript – Dynamic functionality and user interactions.

Node.js – Backend server environment.

Express.js – Server-side functionality and API integration.

Anthropic API – AI-powered tutor functionality.

YouTube Embed – Video lesson integration.
